# Student Management System

A beginner-friendly Python console-based project.

## Features
- Add Student
- View Students
- Search Student
- Delete Student

## Technologies Used
- Python
- Lists and Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling

## How to Run
Run the following command:

python main.py

## Note
Student data is stored temporarily in a Python list.
Data is lost when the program exits.
